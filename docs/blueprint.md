# **App Name**: JudgeEase

## Core Features:

- Team Presentation Capture: Dynamically capture information about the teams from a third party data source.
- Configurable Criteria: Define and configure scoring criteria for each team including innovation, techincal implementation, impact, and presentation. The evaluation criteria can be adjusted as a property by a privileged user.
- Team Evaluation: Judges can input scores and optional comments for each team based on evaluation criteria. Judges can navigate between teams and criteria as needed during live presentation and evaluation.
- Progress Indicator: Display a progress summary indicating teams that have been fully evaluated versus those that are pending based on input criteria. 
- Automatic Save: Implement automatic score saving with manual override.
- Review and Submit: Provide a final screen that reviews all teams' criteria before submitting completed evaluation.

## Style Guidelines:

- Primary color: A professional blue (#3498DB) to convey trust and reliability.
- Background color: Light grey (#ECF0F1) for a clean, non-distracting interface.
- Accent color: Orange (#E67E22) for CTAs like the submit button.
- Body and headline font: 'Inter' sans-serif for a clear and modern look.
- Use checkmark icons to indicate completed evaluations.
- Design a clear layout where each team and evaluation criteria are well spaced and distinct to ease navigation and reduce error.
- Use subtle transition animations to give feedback when auto-saving scores.
